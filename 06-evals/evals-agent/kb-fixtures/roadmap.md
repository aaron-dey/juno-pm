# Strategy: Q3–Q4 2026 Roadmap Priorities

*Rocketship internal strategy doc — effective 2026-09-01*

- Committed priorities for Q3 2026: mobile playback stability, SSO rollout for Enterprise+ accounts, and localized billing (EU/UK currencies and tax handling).
- Dark mode, custom theming, and other purely cosmetic requests are explicitly deferred to Q1 2027. Do not recommend P0/P1 action on these regardless of request volume, unless the request is tied to an accessibility legal requirement (see Classification Overrides doc).
- Any fix that would require re-architecting the billing pipeline is out of scope for this fiscal year. Flag such requests as "Dependency: billing re-architecture" and recommend it be routed to the Q1 2027 planning cycle rather than actioned now.
- Mobile crash-rate reduction is the single highest-weighted committed priority this quarter; any P0 mobile crash report should be treated as directly supporting an already-funded initiative, not a new ask.
